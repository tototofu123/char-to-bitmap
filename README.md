# Char to Bitmap Converter 🔠🖼️

A Python-based utility that converts text, characters, and strings into high-resolution bitmap images, useful for embedded systems, display drivers, and creative typography.

## ✨ Key Features
- **Font Customization**: Supports various font families and sizes.
- **Batch Processing**: Convert entire sentences or specific character sets at once.
- **Bitmap Export**: Generates clean, high-contrast bitmap data.

## 🛠️ Tech Stack
- **Python 3**
- **Pillow (PIL)** for image processing
- **JavaScript (Vanilla)** for the web-based preview tool

## 📂 File Structure
- `index.html`: Web-based interface for character preview.
- `script.js`: Logic for pixel-data generation and visualization.
- `style.css`: Responsive UI for the converter tool.
- `.gitleaks.toml`: Security configuration for secret scanning.
